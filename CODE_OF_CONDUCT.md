# Code of conduct

This project welcomes respectful, good-faith collaboration.

Participants are expected to:

- discuss ideas and code without personal attacks;
- give actionable technical feedback;
- respect privacy and responsible-disclosure boundaries;
- avoid using project spaces to promote unauthorised testing or harm;
- credit sources and contributors accurately.

Harassment, discrimination, threats, deliberate disclosure of private information, and repeated bad-faith disruption are not acceptable. Maintainers may edit, hide, or remove content and restrict participation when necessary to protect the community.
