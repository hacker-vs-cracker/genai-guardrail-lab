# AI-assisted development disclosure

AI assistance was used for design exploration, code drafting, refactoring suggestions, documentation editing, and test-case brainstorming during the development of this repository.

The maintainer reviewed, modified, organised, and tested the implementation. AI output was not treated as an authoritative security source. The maintainer remains responsible for defects, licensing decisions, security issues, project claims, and ongoing maintenance.

Contributors are encouraged to disclose substantial AI assistance in pull requests and to validate generated code with the same standards applied to any third-party contribution.
